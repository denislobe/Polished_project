This project is involved in my master thesis where i work with a tilt series of 4D-SPED data

The code is divided in three sections, this being the preprocessing, template matching, and correction

The preprocessing module contains functions that i have implemented for the workflow such as ROI selection, calibration and so on.

The template matching script makes a class of results for the tilt data and saves it on the relative output path

The correction algorithm is the proposed correction done after template matching, here the input path should correspond to the results saved in the outputs folder

The notebook was used as the main file for testing and running the code
